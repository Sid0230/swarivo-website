# SWARIVO Security Policy

If you discover a security vulnerability in SWARIVO, please report it privately rather than publishing the details first.

Please include:
- the affected page or component
- a clear description of the issue
- steps to reproduce
- screenshots or logs where safe to share
- any suggested remediation

Do not include passwords, private keys, payment details, or other sensitive personal information in a report.

SWARIVO will review reports and take appropriate action based on severity and reproducibility.
